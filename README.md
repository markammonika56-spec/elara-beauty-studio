
# ✨ ELARA BEAUTY STUDIO

### Elegant Beauty. Timeless Confidence.

A modern, responsive beauty salon website concept designed to showcase salon services, bridal beauty offerings, and customer enquiry options through an elegant online experience.

> **Portfolio Demo:** ELARA BEAUTY STUDIO is a fictional salon brand created for demonstration and portfolio purposes. All service prices and business details are sample content.

---

## 🌸 Project Overview

ELARA BEAUTY STUDIO is a front-end website project built to demonstrate a clean, premium-style website for a beauty salon.

The design combines soft colours, elegant typography, service highlights, and simple navigation to create a welcoming digital experience.

## ✨ Features

- Responsive layout for mobile and desktop screens
- Elegant salon-inspired design
- Hero section with prominent call-to-action buttons
- Beauty service cards with sample pricing
- Bridal beauty showcase
- About and contact sections
- Mobile navigation menu
- Smooth scrolling for on-page navigation
- WhatsApp enquiry link placeholder

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Mobile menu and navigation interactions
- **Google Fonts** — Typography
- **Unsplash** — Demonstration imagery

## 📱 Responsive Design

The website includes responsive styling intended to adapt the layout to different screen sizes. Final appearance should be checked on both mobile and desktop devices.

## 🎯 Project Goals

- Practise front-end web development
- Build a portfolio-ready salon website concept
- Demonstrate layout, styling, and basic JavaScript interactions
- Explore how a small beauty business could present its services online

## 🔧 Future Improvements

- Connect the enquiry button to the salon's actual WhatsApp number
- Add real salon contact information with the owner's permission
- Add a working appointment booking system
- Improve accessibility and test across browsers
- Add a backend only if the final business requirements need one

## ⚠️ Demo Disclaimer

This project is a fictional portfolio demonstration, not an official salon website. The brand, service prices, and business information are illustrative. Real business details and customer-facing features must be configured and tested before production use.
